BetterHalf ♥ 帮助与支持

两个人的小宇宙：在一起天数、纪念日、回忆、每日一问、宠物和桌面小组件。

怎么让另一半也用上？

TA 下载 BetterHalf 后，在开始页点「TA 已经在用？靠近加入」；你在「设置 → 和 TA 的手机同步」里点「连接」，TA 点「接受」即可。两部手机需要在附近（同一 Wi-Fi 或打开蓝牙）。

数据会上传到哪里吗？

不会。所有数据只保存在你们自己的手机里，同步也是手机之间直接传输。换手机前请在「设置 → 导出备份」保存一份。

怎么把天数或宠物放到桌面 / 锁屏？

长按桌面空白处 → 左上角「编辑」→「添加小组件」→ 搜索 BetterHalf。长按已添加的小组件 →「编辑小组件」可以选择显示在一起天数、里程碑或某个纪念日。

宠物的 AI 聊天 / AI 生成形象怎么开启？

在「宠物 → 右上角菜单 → AI 设置」填写你自己在 DeepSeek、OpenAI、Anthropic 等服务商申请的 API Key。费用由服务商向你的账号收取，App 不收费。不填写也可以和宠物聊天（使用内置的离线回复）。

上传宠物照片为什么没有自动抠图？

抠图使用 iPhone 的神经网络引擎，需要 iOS 17 以上的真机；如果照片里宠物不够清晰，会自动改用圆形头像。也可以换一张主体更清楚的照片。

忘记开启的面容 ID 锁打不开怎么办？

面容 ID 失败时可以输入 iPhone 锁屏密码解锁。
